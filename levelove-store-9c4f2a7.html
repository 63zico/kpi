User Flow

역할별 사용 흐름

사장님, 매니저, 직원이 서로 다른 화면에서 해야 할 일만 하도록 분리합니다.

등록 전 핵심 플로우
Owner

사장님 플로우

  1. 매장 이름과 기본 설정을 저장합니다.
  2. 직원과 역할을 등록하고 개인 링크를 발급합니다.
  3. 역할별 성과, 랭킹, 팀 챌린지를 조정합니다.
  4. 직원화면과 테스트 도구로 제출/승인 흐름을 확인합니다.
직원 세팅 매장 세팅
Manager

매니저 플로우

  1. 오늘 확인할 것에서 운영 포인트를 입력합니다.
  2. 직원 제출과 진행 중인 기록을 확인합니다.
  3. 승인 대기에서 제출 내용을 검수합니다.
  4. 필요한 공지와 팀 목표만 업데이트합니다.
오늘 확인 승인 대기
Staff

직원 플로우

  1. 직원 전용 링크로 자기 이름 화면에 접속합니다.
  2. 출근 전 기분과 오늘 목표를 확인합니다.
  3. 역할에 맞는 성과 미션을 완료합니다.
  4. 퇴근 전 마감 체크 후 제출합니다.
